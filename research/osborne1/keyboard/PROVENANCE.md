# Provenance — osborne_keyboard_pinout.html

- **What:** archived copy of the Osborne 1 keyboard pinout page from pinouts.ru.
- **Source URL:** https://old.pinouts.ru/InputCables/osborne_keyboard_pinout.shtml
- **Captured:** 2026-10-08 (local), via `curl -sL`, verbatim HTML as served.
- **Original author:** David Knoll (contributor), © pinouts.ru team / respective
  contributors, 2000–2024. The author states the pinout "came from the Osborne 1
  Technical Manual" and was checked against a PCB; the page shows 4/4 corroborating
  reports.
- **Why archived:** this is the reference for the P4 keyboard connector pinout
  (rows A0–A7, cols D0–D7, pin 18 NC, pin 19 = +12V via jumper J6 + R21 22Ω) and the
  full key matrix map used by #47 (USB keyboard adapter) and #45 (KVM). Upstream
  pages move or vanish; per research/README.md this in-repo copy is the authoritative
  safety copy.
- **Status:** verbatim capture, unmodified. If the upstream page is re-fetched, record
  the new date here.
